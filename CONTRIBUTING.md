# Contributing to sparkcc/governance

First off, thanks for taking the time to contribute! ❤️

SparkCC is a member run organisation and we encourage any feedback or ideas on how the organisation is managed!

## I Have a Question

> If you want to ask a question, we assume that you have read the [SparkCC wiki](https://wiki.sparkcc.org/en/home).

Please note that this repo is for the governance of SparkCC - For questions not about the policies or constitution of SparkCC, please ask in the [SparkCC Slack](https://sparkcc.slack.com/)

Before you ask a question, it is best to search for existing [Issues](https://github.com/SparkCC/sparkcc-governance/issues) that might help you. In case you have found a suitable issue and still need clarification, you can write your question in this issue.

If you then still feel the need to ask a question and need clarification, we recommend the following:

- Open an [Issue](https://github.com/SparkCC/sparkcc-governance/issues/new).
- Provide as much context as you can about your governance or policy question.

We will then take care of the issue as soon as possible.

## I Want To Contribute

SparkCC can only accept change requests from members of the SparkCC committee.

We consider open and respectful discussion to be a core part of what SparkCC is about. To achieve that goal, we want to be as transparent as possible with our members. Members are welcome to submit questions/ideas on policy or the constitution via the [Github issue tracker](https://github.com/SparkCC/sparkcc-governance/issues) and discussions are welcomed!

Please note that you are expected to follow our [Code of Conduct](https://github.com/SparkCC/sparkcc-governance/blob/main/sparkcc-code_of_conduct.md) at all times, including in the issues section of this repository

## Style guides

These are the requirements when submitting any changes or new documents

### General

- All documents must use the [markdown syntax](https://www.markdownguide.org/basic-syntax/)
- All clauses must be numbered
- Top level clause (i.e. 1.0, 2.0 etc) headings must be Heading2 `##`
- Sub Clause (i.e. 1.1, 2.23 etc) headings must be Heading3 `###`
- No spelling mistakes should be present
